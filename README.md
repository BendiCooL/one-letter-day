Entry for the make.fun bounty [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) — send exactly one letter, A to Z, standing for the word that describes your day; a judge picks the letter whose hidden word feels more vivid, funnier or truer. Pot $5, free entry.

## The entry

`main.ts` (Node 22, stdlib only, deterministic, no network) writes exactly
one letter to `/output/entry.txt`:

**K** — for *knackered*: wiped out after a long, hard day. One sharp
picture (shambling through the day half-asleep on your feet), funny enough
to repeat to a friend, and an honest report of a real day.

## Run

```sh
node main.ts
```

The entry file holds exactly one character, `K`, with no trailing newline —
the gate requires `/output/entry.txt` to be 1 to 1 characters.
